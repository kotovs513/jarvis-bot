# 🤖 Джарвис — твой ассистент в Telegram

Пишешь боту текстом или голосом → он понимает, что это (задача / напоминание / заметка) → складывает в базу Notion. Напоминания присылает вовремя обратно в Telegram.

Инструкция рассчитана на человека, который **не умеет писать код**, но у которого есть **Cursor**. Просто повторяй шаги. Если что-то не получается — скопируй ошибку в чат Cursor и попроси починить.

---

## Что понадобится

Собери сначала ключи, дальше всё быстро: токен Telegram, ключ OpenAI и два значения от Notion.

### 1. Токен Telegram-бота
1. Открой Telegram, найди **@BotFather**.
2. Напиши `/newbot`, придумай имя и юзернейм (заканчивается на `bot`).
3. BotFather пришлёт строку вида `1234567890:AAExxxxxxxxx` — это твой `TELEGRAM_TOKEN`.

### 2. Ключ OpenAI (для голоса и умной сортировки)
1. Зайди на **platform.openai.com** → войди/зарегистрируйся.
2. Пополни баланс на $5 (этого хватит надолго — расшифровка и сортировка стоят копейки).
3. **API keys** → **Create new secret key** → скопируй строку `sk-...` — это `OPENAI_API_KEY`.

### 3. Notion (куда падают задачи) — два значения

**Сначала создай базу.** В Notion сделай новую страницу → вставь блок **Table** (база данных). Назови её как хочешь (например «Входящее от Джарвиса») и сделай ровно три колонки с такими названиями:

| Колонка    | Тип       | Зачем                          |
|------------|-----------|--------------------------------|
| `Название` | Title     | сам текст задачи (уже есть по умолчанию — переименуй) |
| `Тип`      | Select    | Задача / Напоминание / Заметка |
| `Когда`    | Date      | время напоминания              |

> Названия колонок должны совпадать буква-в-букву, иначе бот не запишет. Значения для `Тип` создавать заранее не нужно — Notion добавит их сам.

**Теперь ключ интеграции (`NOTION_TOKEN`):**
1. Открой **notion.so/my-integrations** → **New integration**.
2. Дай имя «Джарвис», выбери свой воркспейс → **Submit**.
3. Скопируй **Internal Integration Secret** (`secret_...` или `ntn_...`) — это `NOTION_TOKEN`.

**Дай интеграции доступ к базе:**
4. Открой свою базу в Notion → справа вверху меню **⋯** → **Connections** (Подключения) → найди «Джарвис» и подключи.

**ID базы (`NOTION_DATABASE_ID`):**
5. Открой базу как отдельную страницу, посмотри на ссылку в браузере:
   `notion.so/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...`
   Набор из **32 символов** до знака `?` — это `NOTION_DATABASE_ID`.

## Запуск на своём компьютере (через Cursor)

Так удобно проверить, что всё работает. Минус: бот живёт, только пока открыт Cursor. Для «всегда онлайн» — см. следующий раздел.

1. **Открой папку `jarvis-bot` в Cursor** (File → Open Folder).
2. **Создай файл `.env`**: скопируй `.env.example`, переименуй копию в `.env`, вставь свои ключи.
3. **Открой терминал в Cursor** (меню Terminal → New Terminal) и выполни по очереди:
   ```
   pip install -r requirements.txt
   python run_local.py
   ```
4. Когда увидишь строку `Джарвис запущен` — открой своего бота в Telegram, напиши `/start` и попробуй:
   - «напомни завтра в 10 позвонить инвестору»
   - «сделать лендинг к пятнице»
   - пришли голосовое

Строки появятся в базе Notion, напоминание придёт вовремя. Чтобы остановить — нажми `Ctrl+C` в терминале.

> Не разбираешься в командах? Просто напиши в чате Cursor: «запусти этот проект по README» — он сделает.

## Чтобы работал 24/7 (деплой на Railway)

Компьютер выключать нельзя, если бот запущен локально. Чтобы он жил в облаке бесплатно/дёшево:

1. Зарегистрируйся на **railway.app** (через GitHub — проще всего).
2. Залей папку `jarvis-bot` в репозиторий на GitHub (в Cursor: вкладка Source Control → Publish). `.env` НЕ попадёт в репозиторий — так и надо, это секрет.
3. В Railway: **New Project → Deploy from GitHub repo** → выбери свой репозиторий.
4. Открой проект → вкладка **Variables** → добавь по одной переменные из своего `.env`:
   `TELEGRAM_TOKEN`, `OPENAI_API_KEY`, `NOTION_TOKEN`, `NOTION_DATABASE_ID`, `TIMEZONE`.
5. Railway сам увидит `Procfile` и запустит бота. Всё — он онлайн круглосуточно.

> Чтобы напоминания не терялись при перезапуске, в Railway можно добавить **Volume** и примонтировать к папке проекта — тогда файл `reminders.db` сохранится. Для старта не обязательно.

## Как это работает (коротко)

- `bot.py` — сам бот: приём сообщений, Whisper, сортировка, запись в Notion, напоминания.
- `run_local.py` — запуск на своём компьютере (читает `.env`).
- `requirements.txt` — список библиотек.
- `.env` — твои секретные ключи (не выкладывай никуда).
- `Procfile` — как запускать в облаке.

## Что уже умеет (кроме базового)

- **Понимает намерение (агент)** — сначала распознаёт, что ты хочешь, потом действует:
  - записать дело (можно несколько из одного сообщения);
  - показать список — «какие задачи на сегодня?», «что просрочено?», «покажи всё»;
  - отметить готовым словами — «отметь лендинг готовым», «сделал пост»;
  - перенести — «перенеси звонок на завтра в 15:00»;
  - удалить — «удали заметку про…»;
  - просто ответить на вопрос/совет.
- **Кнопка «✅ Готово»** под задачей и напоминанием — ставит Статус=Готово в Notion.
- **Напоминание за день до события** — если у напоминания есть дата, придёт ещё и за 24 часа.
- **Утренняя сводка** — каждое утро в 9:00 (по TIMEZONE) бот шлёт план на день. Вызвать вручную — команда `/today`.
- Напоминания **восстанавливаются из Notion** при перезапуске, так что переживают редеплой.

Настройки (необязательные переменные в `.env` / Railway):

- `MORNING_HOUR` — час утренней сводки (по умолчанию 9).
- `CHAT_ID` — если задать, сводка и напоминания работают сразу после перезапуска. Без него — после первого твоего сообщения боту.
